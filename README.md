## 🔗 Bookmarklets

### Confluence Shortlink
A browser bookmarklet that extracts the shortlink and page title from a Confluence page and copies it to your clipboard as rich text.

**Features:**
- Extracts page title and shortlink from Confluence pages
- Copies rich HTML link to clipboard (works with Word, Outlook, Confluence)
- Also copies plain text format as fallback
- Shows success message when link is copied
- Works on any Confluence instance

**Usage:**
1. Visit [docs/bookmarklets/confluence-shortlink-bookmarklet.html](https://eightysixth.github.io/scripts/docs/bookmarklets/confluence-shortlink-bookmarklet.html)
2. Drag the "Confluence Shortlink" button to your bookmarks bar
3. Navigate to any Confluence page and click the bookmarklet
4. Paste the link into any rich text editor
