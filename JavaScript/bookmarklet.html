Confluence Shortlink Bookmarklet

Quickly copy rich text links from Confluence pages to your clipboard. Perfect for pasting into emails, documents, and other applications.

📌 Installation

Drag and drop this button to your bookmarks bar:

Confluence Shortlink

You can also right-click the button and select "Add as bookmark"

✨ Features

  • Extracts page title and shortlink from Confluence pages
  • Copies rich HTML link to clipboard (works with Word, Outlook, Confluence)
  • Also copies plain text format as fallback
  • Shows success message when link is copied
  • Works on any Confluence instance

🚀 How to Use

  • Navigate to any Confluence page
  • Click the bookmarklet button
  • Paste the link into any rich text editor
